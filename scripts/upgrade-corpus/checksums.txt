# Pinned release assets used to produce the upgrade corpus.
#
# Each line is `sha256  asset-name`, matching the digest GitHub records for that
# release asset (`gh api repos/<slug>/releases/tags/<tag>`). generate.sh refuses
# to run against an asset that is not listed here: a fixture is only evidence
# about a real release if the bytes are the ones that release shipped.
#
# Entries exist per host triple, because the corpus can be regenerated on any
# machine that can run the old binaries. Add the triple you need after checking
# the downloaded file against the digest GitHub reports for it.
#
# Three assets, for the one wing this corpus holds: the notes ref spans three
# writing eras and each era needs the binary that wrote it.
#
# Every filename below spells the project's former name, and must keep spelling
# it. These are 0.9.x-and-earlier assets that were published under that name;
# the bytes and the filename both shipped years-worth of installs ago and no
# rename can reach back and change them. A filename here that has been
# modernised is simply a filename that resolves to nothing.
